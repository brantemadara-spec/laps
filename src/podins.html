Kā lietot Blenderī

Gatavā Blender faila atvēršana

  1. Lejupielādē NO_KOKA_UZ_KOKU_Podina_prototips.blend.
  2. Blender izvēlies File → Open un atver failu.
  3. Objektu sarakstā Outliner izvēlies vajadzīgo detaļu. Nospied Numpad . vai View → Frame Selected, lai to pietuvinātu.
  4. Ar peles vidējo pogu grozi skatu, ar ritentiņu pietuvini; Shift + vidējā poga pārvieto skatu.

Koda palaišana

  1. Saglabā esošo darbu un atver File → New → General. Skripts izdzēš visus aktīvās ainas objektus.
  2. Atver darbvietu Scripting, Text Editor spied New.
  3. Ielīmē visu kodu vai atver lejupielādēto PY failu.
  4. Spied Run Script vai novieto kursoru koda logā un nospied Alt+P. Pagaidi, līdz pabeigtas Boolean darbības.
  5. Saglabā ar File → Save As. Mainot kodu, palaid to no jauna, lai atjaunotu ģeometriju.

Daļai stiprinājumu un palīgģeometrijas pozīcijas kodā dotas atsevišķi. Mainot podiņa pamatizmērus, pārbaudi arī tapu, skrūvju ausu, centrēšanas gredzena un drenāžas novietojumu. Nomērītais sausā masas podiņa biezums var atšķirties no koda parametriem.

Atsevišķas detaļas eksports drukai

Kods pats nesaglabā STL failus. No ģenerētās ainas eksportē vienu izvēlētu formas detaļu.

  1. Atlasi vienu no 01–09 objektiem. Serdeņus 04_CORE_3MM / 05_CORE_4MM / 06_CORE_5MM izvēlas pēc vajadzīgās sienas; šajā versijā atsevišķa atsauces podiņa nav.
  2. Izvēlies File → Export → STL (.stl) un ieslēdz Selection Only un Apply Modifiers.
  3. Šajā kodā viena koordinātu vienība ir viens milimetrs. STL eksportam lieto Scale 1 un atstāj Scene Unit izslēgtu, ja šī opcija ir redzama.
  4. Atver STL printera slicerī un pārbaudi mērogu: pamatnes un augšējās plāksnes diametram jābūt 150 mm. Izvēlies drukas orientāciju un novieto detaļu uz galda.

V4.1 kataloga detaļu pozīcijas ir apskatei. Pirms STL drukāšanas detaļas jāorientē un jānovieto uz drukas galda. Sietiņu eksportē atsevišķi. Podiņa kods izveido stiprinājumu caurumus, bet ne metāla skrūvju un vītņstieņu modeļus.

Projekta piezīmes

Piezīmes par jauno prototipu

Gala podiņa ārējie izmēri: Ø90 mm augšā, Ø65 mm apakšā, H70 mm.

  1. Maināmi serdeņi sienām: 3 mm / 4 mm / 5 mm.
  2. Dibena biezums: 4 mm.
  3. Ir divdaļīga ārējā forma, pozicionēšanas tapas un M6 stiprinājumu vietas.
  4. Ir pārplūdes kamera liekajai masai.
  5. Ir drenāžas pamatne un sietiņš.
  6. Metāla M6/M12 stiprinājumi nav paredzēti 3D drukai.
  7. Jāizvērtē PETG tolerances, manifold kļūdas un savietojamība pirms printa.
  8. Pārbaudīt ne tikai STL eksportu, bet tieši: sienu biezumu (wall thickness), spraugas (clearances), Boolean kvalitāti, tapu/caurumu tolerances, pārplūdes kameras savietojamību (overflow fit), serdeņa STOP pozīciju un vai visas detaļas ir manifold.

Norādītie gala izmēri un biezumi ir projekta mērķi. Atjauninātās V4.1 ģeometrijas atbilstība tiem un atrastās neatbilstības ir norādītas pārbaužu sadaļā.
